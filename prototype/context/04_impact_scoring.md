# Impact scoring

Each merchant stands for one brief quote and the cause behind it. The impact score (0–10) says how much fixing that cause would move the funnel. It sets the switcher order and is shown on each merchant.

**Formula:** `impact = 2 × (0.4 × reach + 0.3 × severity + 0.2 × evidence + 0.1 × commercial)`, each rated 1–5.

- **Reach:** how many of the brief's 100 merchants the cause touches.
- **Severity:** does it stop a launch, cause a switch-off, or just add friction?
- **Evidence:** how strongly we showed it on screen (reproduced = 5, explained = 4, partly = 3, open = 2).
- **Commercial:** link to renewals or upgrades.
