# Appendices to the memo

Evidence behind "Getting merchants live on the AI Agent, and keeping them live" (Mike Rourke, 28 September 2026). Each file carries source tags: `[product]` seen on screen, `[mike]` my own walkthrough, `[help]` help centre, `[pricing]` pricing page, `[provider]` a platform's own docs, `[persona]` persona tests, `[inference]` reasoning.

| Appendix | File | What it holds |
|---|---|---|
| A | `A_hypotheses.md` | 13 hypotheses written before touching the product, then tested against two walkthroughs and the pricing page: confirmed, killed, revised or left open. Earlier versions kept as `A_hypotheses_v1.md` (brief only) and `A_hypotheses_v2.md` (plus my notes and the help centre). |
| B | `B_root_causes.md` | The four root causes the memo uses, each explaining more than one funnel symptom and resting on product evidence. |
| C | `C_integration_guides_check.md` | All 50 integration guides on help.zaapi.com checked against LINE, Meta and Shopee's own documentation: what's out of date, what expires, and what history the AI could use but doesn't get. |
| D | `D_brief_coverage.md` | Every quote, funnel row and claim in the brief mapped to the evidence that covers it. |

Test evidence is in `../research/` (walkthrough log, persona test logs v1 and v2, persona summaries, competitor research). The prompts used are in `../prompts/master_prompts.md`.
